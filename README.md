# dsh-tidewatch

**DeepSeek 峰谷时刻挂件**：一枚常驻在界面右下角、可拖拽吸附的潮汐挂件，告诉你此刻是峰期还是谷期、距下一阶段还有多久、本次会话花了多少钱。

- 状态点：**峰期橙红 / 谷期蓝绿**，一眼可辨
- 折叠态：`● 峰期 距谷期 03:33 · ¥0.12`
- 展开态（点击展开）：官方峰谷时段表（北京时间）、当前档位价格、本次会话 Token 明细、**DeepSeek 账户余额**、币种切换
- 计费：官方峰谷两档价格（美元口径；含 基础价 / 首版峰谷价 / V4.1 Flash 新价 三段历史档），按每次调用**实际发生时刻**的档位计价，缓存命中/未命中分开
- 峰谷判定：周末、中国法定节假日（2026 年官方安排表内置）与调休上班的周末全天按谷期计价
- 币种：默认人民币显示（直接取官方中文定价页数字），展开面板可一键切换美元（官方英文页数字，4 位小数）
- 跟随 GUI 亮/暗主题（`--dsw-*` 变量）
- 前端优先采用 DSH 官方 UI 原语（shell 共享模块表中的 `@deepseek-ai/dsh-client-ui-primitives`）：状态点 `StateDot`、标签 `Tag`、悬浮提示 `Tooltip`、外点关闭 `useDismissOnOutsidePointer`，观感与官方控件一致；老版 shell 的模块表若没有该包，自动降级到内置实现，功能不受影响
- 账户余额：读 DSH 的账户服务（`ctx.remote.account.getBalance`），显示**充值余额 / 礼金余额 / 合计**与读数时刻；查询由宿主执行，本插件不接触 API Key、不直接发请求、不落盘
- 适用边界：峰谷档位与金额只对 **DeepSeek 自家模型**成立。换用其他提供商（Claude / GPT / Kimi 等）时，胶囊显示「不适用」、金额显示「—」，时段表与价目保留但标注「仅 DeepSeek 模型适用」，余额仍如实显示 DeepSeek 账户的数字 —— 宁可不给数字，也不拿 flash 价硬凑
- 挂件形态：**右下角常驻、可拖拽**；松手后靠近左右边缘自动吸附，位置记在 localStorage，吸附到左侧时内容镜像排列
- 点击交互：单击挂件弹出**轻量泡泡**（本次会话 / 余额 / 峰谷三块摘要，每块可在面板里单独关掉）；点「详情 ›」进入完整面板
- 动效与声音：金额变化时**数字滚动**；点击与余额预警各有**合成提示音**（WebAudio 生成，无音频素材、零版权风险，面板里可关）
- 余额预警：余额低于阈值（默认 ¥10）时提示一次，回升后重新武装；阈值与开关都持久化
- 形象素材：挂件使用社区共创的 DeepSeek 娘「大肥鱼」立绘（原图存于 `lib/assets/mascot/`，压缩后内嵌进客户端 bundle，因此装好即见，无需联网取图）。形象属社区二创，版权归各自创作者所有；**如权利人要求，将立即替换或移除**

## 峰谷时段（官方依据）

DeepSeek 官方自 2026-08-17 起实施峰谷分时定价：

| 时段（UTC） | 北京时间 | 档位 |
|---|---|---|
| 01:00 – 04:00 | 09:00 – 12:00 | 峰 |
| 04:00 – 06:00 | 12:00 – 14:00 | 谷 |
| 06:00 – 10:00 | 14:00 – 18:00 | 峰 |
| 10:00 – 次日 01:00 | 18:00 – 次日 09:00 | 谷 |

谷期价格为峰期的一半。徽章按 UTC 窗口判定当前档位（官方英文页即按 UTC 小时书写），周几与法定节假日按北京自然日判定（官方中文页把周期锚在「北京时间周一至周五」上）；两种读法在当前窗口取值下等价——窗口均落在同一北京自然日内、且不成对跨越 UTC 日界。时段表展示一律按北京时间。

**周末与法定节假日规则**：周六/周日全天按谷期计价（2026-08-23 00:00 北京时间起，官方公告原文「周六、周日全天不再区分峰谷时段，统一按低谷时段价格收取调用费用」）；中国法定节假日全天按谷期计价、无峰谷切换、**无生效时间**（官方定价页脚注，2026-10-10 核对：「高峰时段为北京时间周一至周五（**不含中国法定节假日**）……包括周末及中国法定节假日全天均为空闲时段」）；调休上班的周末同样全天谷期（官方 2026-09-19 说明：「调休上班的周末、中国法定节假日全天均按空闲时段计费」）。下一阶段切换点为下一个工作日首次进入峰时。节假日表依据《国务院办公厅关于 2026 年部分节假日安排的通知》（国办发明电〔2025〕7号，共 33 天）：元旦 1/1–1/3、春节 2/15–2/23、清明 4/4–4/6、劳动节 5/1–5/5、端午 6/19–6/21、中秋 9/25–9/27、国庆 10/1–10/7。

## 计费口径

- 价格单位：美元 / 1M tokens（官方**英文**定价页口径，也是本插件的唯一计费基准），成本 = 输入未命中 × cacheMiss + 输出 × output + (缓存读 + 缓存写) × cacheHit；其中「输出」已含推理 token
- 人民币数字另存一份官方**中文**定价页数字原样用于展示，不做汇率换算——官网两个模型的隐含汇率并不相同（flash 约 6.67、pro 约 6.82），统一换算会让 pro 的元数字比官网低约 2%
- **三段价格时代**，按调用发生时刻选档（历史正确性；档位顺序为 缓存命中 / 输入未命中 / 输出）：

  | 时代 | 时间范围（UTC） | deepseek-flash 档位 |
  |---|---|---|
  | 基础价 | 2026-08-16 16:00 之前 | 0.0028 / 0.14 / 0.28 |
  | 首版峰谷价 | 2026-08-16 16:00 ~ 2026-09-10 04:00 | 峰 0.014 / 0.44 / 1.32，谷为峰的一半 |
  | V4.1 Flash 新价 | 2026-09-10 04:00 起 | 峰 0.006 / 0.3 / 1.2，谷为峰的一半 |

- 每次调用的费用按**事件发生时刻**的档位计算，跨峰谷切换与跨调价均不漂移
- 账本金额以美元存储；人民币显示直接取官方中文页数字（默认），美元显示取官方英文页数字（4 位小数）

## 安装

> 需求：Node.js ≥ 20 + 带 `dsh plugin` 命令的 DeepSeek Harness。

```sh
# 方式一：从 GitHub 直装（推荐，跟随 main 最新）
dsh plugin --profile web add github:KhalilYamber/dsh-tidewatch

# 方式二：链接本地仓库目录（改完源码即时生效，开发时最省事）
dsh plugin --profile web add link:/path/to/dsh-tidewatch

# 方式三：从 Release 的 tgz 安装（可固定版本、可离线）
#   先到 Releases 页面下载 dsh-tidewatch-<版本>.tgz（当前为 1.1.9），然后：
dsh plugin --profile web add ./dsh-tidewatch-1.1.9.tgz
```

> **本仓库只保留当前版本的 tgz**：历史版本（0.1.0 ~ 1.1.9）已归档移出仓库，只剩 `dsh-tidewatch-1.1.9.tgz`。旧版多含已修正的计价缺陷（金额恒显示 ¥0.00），不要再用它们安装。

> **npm 渠道已暂停**：npm 上仅有一个 2026-08-22 发布的旧版本（1.0.6），其价格与规则均已过时。请勿安装该版本，也不要据它判断当前计价——以上面两种方式为准。

安装后重启 `dsh web` 生效，输入框右侧会出现潮汐徽章。

## 使用

- 徽章**注册在官方输入框停靠插槽 `conversation.composer.dock`**（官方统计行 `StatsPills` 与 `ContextMeter` 同槽），渲染进输入框下方那条 flex 行，与「48 轮 403 步」「缓存命中 xx%」等条目并列；间距、垂直对齐与窄屏换行全部由官方布局给出，插件不覆盖其样式，也不做 DOM 探测
- 点击徽章展开/收起详情面板：时段表、当前档位价格、Token 明细、币种切换（¥ / $）
- 点击「本次会话费用」行可展开**分模型花费明细**（各模型的 token 与花费分别列出，合计 = 分模型之和）
- 币种选择即时生效并记住；人民币 2 位小数，美元 4 位小数

## 数据流

```
模型调用 usage 块（assistant/message 事件，DSH 0.1.7-rc.2 起唯一带 usage 的事件）
        │  lib/index.js：costUsage 会话投影（zod schema 校验）
        ▼
  token 桶 + 美元成本（按事件时刻峰谷档位）
        │  useProjection('costUsage')（浏览器端）
        ▼
  lib/client.js：统计行胶囊渲染（秒级倒计时 + 汇率换算显示）
```

## 开发与验证

```sh
DSH_CHECKOUT=<harness 源码根目录> bash scripts/build.sh   # 语法检查 + zod junction
node test/verify.mjs                                       # 全套自检（峰谷数学、双份常量一致性、计费口径回归、归属判据回归）
```

> Git Bash 下 `DSH_CHECKOUT` 需用 **Windows 形式**路径（如 `D:/DeepSeek-Harness/DSHAR工作目录/deepseek-harness-src`）：传 `/d/...` 会被 Node 解析成 `D:\d\...`，生成悬空 junction —— 插件是 link 安装，坏链接会在下次 `dsh web` 启动时导致插件装配失败（`Cannot find package 'zod'`）。脚本已在**替换链接之前**校验解析结果，坏路径当场报错且不留破坏。

## 已知限制

- 价格表内置，含三段价格时代（基础价 / 首版峰谷价 / V4.1 Flash 新价）；V4-Pro 为官方 2026-08-17 价；官方定价页脚注(2)与更新日志（2026-09-10）声明 2026-09-14 之后继续提供 V4 Pro 服务、**计费方式保持不变**（如有变动另行通知），故 pro 恒按自身价目计费，换价分界 `V4_PRO_RETIRE_BOUNDARY` 保持哨兵值待官方通知。**官方调价后需手动同步** `lib/pricing.js`（计费）与 `lib/client.js` 的 `DISPLAY_PRICES`（展示）两处常量，并为旧价补一段历史档
- 模型名映射：现役 `deepseek-flash`（V4.1 Flash）；别名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`、`deepseek-v4.1-flash` 均按现役 flash 价计费（见 `MODEL_ALIASES`）
- 时段判定固定按 UTC（官方口径），时段表展示按北京时间（UTC+8）；周末与中国法定节假日全天谷期——节假日表内置 2026 年（国办发明电〔2025〕7号），**2027 年安排官方发布后需手动同步 `CN_PUBLIC_HOLIDAYS`（`lib/pricing.js` 与 `lib/client.js` 两处）**；调休上班的周末按官方口径恒为谷期
- 花费为美元账本 × 固定汇率 6.67 换算人民币（与官方人民币标价一致）；展开面板可切换美元显示
